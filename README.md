## Estado del proyecto

Fase piloto. La versión actual permite registrar series, cargas y repeticiones
de una rutina de gimnasio, con exportación a CSV y JSON.

## Funciones

- Registro de series por día de entrenamiento
- Cambio entre kg y lb
- Exportar datos en CSV y JSON
- Historial de semanas

## Cómo usar

1. Abre `rutina5v5v5.html` en tu navegador.
2. Registra tus series y marca cada una como completada.
