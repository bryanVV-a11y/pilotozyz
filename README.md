# Pilotozyz

App de rutina de gimnasio que registra series, cargas y repeticiones, y te permite
exportar tus datos. Está pensada para llevar un seguimiento simple de tus entrenos.

## Estado del proyecto

Fase piloto. La versión actual funciona en el navegador y guarda los datos localmente.

## Funciones

- Registro de series por día de entrenamiento
- Cambio entre kg y lb
- Marcar series como completadas
- Exportar datos en CSV y JSON
- Historial por semanas

## Cómo usar

1. Abre `rutina5v5v5.html` en tu navegador.
2. Registra tus series, cargas y repeticiones.
3. Exporta tus datos cuando quieras respaldarlos.
